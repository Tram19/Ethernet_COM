
1. Interface — cầu nối giữa 2 layer
Sau này thêm receiver khác không cần sửa Ethernet_COM:

// IUdpReceiver.hpp

2. Register — đăng ký lúc khởi động

SleepMode_Com::Open()
    └── _ethernetCom.Open()        // start ethernet task
    └── comm2.Open()
            └── eth_.RegisterUdpReceiver(local port, this)
                    └── udpReceivers_[0] = { port=local port, receiver=&comm2 }


// Ethernet_COM lưu vào mảng
void Ethernet_COM::RegisterUdpReceiver(uint16_t port, IUdpReceiver* receiver) {
    udpReceivers_[udpReceiverCount_++] = { port, receiver };
}

4. Tóm tắt ownership
program.cpp
    HW::Peripheral::Spi _spi2          ← own SPI duy nhất
    │
    SleepMode_Com
        Ethernet_COM _ethernetCom      ← own ENC28J60, own ethernet task
            ENC28J60 enc_(_spi2)       ← dùng SPI trực tiếp
            udpReceivers_[]            ← bảng đăng ký
        │
        UdpCOMPort comm2(_ethernetCom) ← chỉ biết Ethernet_COM
            Ethernet_COM& eth_         ← không đụng SPI


Ethernet_COM   → owns hardware, owns task, dispatch packet
UdpCOMPort     → chỉ register + nhận callback + gửi qua eth_
SPI            → khai báo duy nhất 1 nơi, truyền xuống bằng reference
